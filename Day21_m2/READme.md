# Validated Persistent Signup Form

A small signup form that validates a user's name and Ethiopian phone number.

The form:

- Requires a name of at least two characters.
- Validates Ethiopian phone numbers using regex.
- Shows clear validation errors.
- Saves valid signup entries to localStorage as JSON.
- Restores saved signup data after page reload.
- Handles missing and corrupted localStorage data.

## How to Open

Open `index.html` in a web browser.
